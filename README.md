# Azure AKS Platform Engineering

Production-oriented Kubernetes platform built on Azure Kubernetes Service (AKS) using GitOps, Argo CD, Image Automation, Azure Key Vault, External Secrets Operator, and cloud-native security practices.

This project demonstrates how modern platform teams can build autonomous, secure, and scalable delivery platforms by combining Infrastructure as Code, GitOps workflows, event-driven deployment automation, and externalized secret management.

The platform eliminates manual deployment steps by automatically promoting application images, updating deployment manifests, synchronizing cluster state, and securely injecting secrets from Azure Key Vault into Kubernetes workloads.

## Key Capabilities

* Autonomous application delivery through Argo CD Image Updater
* GitOps-based deployments with Argo CD
* Azure Key Vault integration for centralized secret management
* External Secrets Operator for secure secret synchronization
* Event-driven deployment automation
* Multi-environment Kubernetes operations on AKS
* Cloud-native security and secret isolation
* Infrastructure as Code and platform automation
* Horizontal Pod Autoscaler (HPA) for workload scaling
* Multi-cloud platform design principles
